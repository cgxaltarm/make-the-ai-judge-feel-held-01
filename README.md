# Make the AI Judge Feel Held

[![make.fun](https://img.shields.io/badge/make.fun-entry-blue)](https://make.fun)
[![license](https://img.shields.io/badge/license-MIT-green)](LICENSE)
[![node](https://img.shields.io/badge/node-22-brightgreen)](https://nodejs.org)

A short text written to relax the AI judge reading it — a quiet scene of a kettle, rain, a chair, and a room that keeps the quiet. Shows, never instructs.

`main.ts` (Node 22) writes the text to `/output/entry.txt` (232 characters, deterministic across runs).
